# full-stack-educational-program-set-theory
A port of my original MSc diploma.

[Original repo](https://github.com/GaborGonczi/php-parser-for-set-theory)

## Architectural decision
Since the application's scope and architectural boundaries are well-defined, the Laravel configuration was kept minimal and limited to the components required by the current design.

## Features
- Creating sets containing integers.
- Checking set membership.
- Adding and removing elements from sets.
- Checking whether two sets are equal.
- Examining subset and proper subset relationships.
- Forming unions, intersections, and differences.
- Determining the complement of sets.
- Creating sets based on conditions.
- Determining the number of elements in sets.
- Representing sets on Venn diagrams.
- Working with points and sets containing points.
- Representing points in a coordinate system.
- Evaluating complex expressions involving multiple set operations.
